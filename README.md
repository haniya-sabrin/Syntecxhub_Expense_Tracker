# 💰 SpendWise – Expense Tracker

SpendWise is a responsive expense tracking web application developed using React.js as part of the **Syntecxhub Web Development Internship**.

## ✨ Features

* Add income and expense transactions.
* View total balance, income, and expenses.
* Delete transactions.
* Fetch sample transaction data using an API.
* Form validation.
* Loading and error handling.
* Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Vite
* JSONPlaceholder API

## ⚛️ React Hooks Used

| Hook        | Purpose                 |
| ----------- | ----------------------- |
| useState    | Manage application data |
| useEffect   | Fetch API data          |
| useRef      | Focus the input field   |
| useMemo     | Optimize calculations   |
| useCallback | Optimize event handlers |

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/haniya-sabrin/Syntecxhub_Expense_Tracker.git
```

Navigate to the project folder:

```bash
cd Syntecxhub_Expense_Tracker/expense-tracker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
