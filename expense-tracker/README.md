# 💰 SpendWise – Expense Tracker

SpendWise is a responsive Expense Tracker web application developed using React.js. It helps users manage their income and expenses, track their balance, and organize transactions through a simple and user-friendly interface.

## 🚀 Features

* Add income and expense transactions.
* Calculate total income, expenses, and balance automatically.
* Delete transactions.
* Validate user inputs.
* Fetch sample transaction data from an external API.
* Display loading and error states.
* Responsive design for desktop and mobile devices.
* Automatically focus the description field using useRef.
* Optimized calculations using useMemo.
* Optimized event handlers using useCallback.

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Vite
* React Hooks
* JSONPlaceholder API

## ⚛️ React Concepts Implemented

| Hook        | Purpose                                  |
| ----------- | ---------------------------------------- |
| useState    | Manage transactions and form data        |
| useEffect   | Fetch sample transactions from API       |
| useRef      | Automatically focus the input field      |
| useMemo     | Optimize income and expense calculations |
| useCallback | Optimize event handler functions         |

## 💻 Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/haniya-sabrin/Syntecxhub_Expense_Tracker.git
```

2. Navigate to the project folder:

```bash
cd Syntecxhub_Expense_Tracker/expense-tracker
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## 🌐 API Used

JSONPlaceholder API:

https://jsonplaceholder.typicode.com/posts?_limit=3

The application fetches sample transaction data from this API.
